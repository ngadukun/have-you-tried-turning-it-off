An entry for the make.fun bounty [Have You Tried Turning It Off?](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b) ($10, top 10 share the pool).

The program writes one funny line a hopeless tech support agent gives a desperate customer to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

> Have you tried turning it off and on again? I have — twice — and if the third time fails, I'll do it slower, with feeling.

The joke: the agent has already tried the classic fix twice, and his grand escalation is doing it again "slower, with feeling" — cheerful uselessness, and the customer is never the butt of it.

## Run

```sh
node main.ts
```

Writes `entry.txt` (122 characters, inside the 1–199 gate) to `$MAKEFUN_OUTPUT_DIR` or `/output`.
